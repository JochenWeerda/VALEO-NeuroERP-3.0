# README-Positionierung und Quellenabgleich — 2026-10-28

Die zweisprachige README stellt Agrarfokus, Prozesskern, Studio und kontrollierte Agentenzugriffe als Produktidee dar. Sie trennt vorhandene Bestandteile von laufender Arbeit und behauptet weder Marktüberlegenheit noch Kundenadoption, Zertifizierungen oder allgemeine Produktivfreigabe.

Quellen: Process-Kernel-Status und Wave-Nachweise; Fuhrpark-MCP-Abnahme vom 9. Oktober (581 Tests nur für diesen Lieferstand); Active Workboard und Adaptive-Workspace-Handoff (Arbeit offen); Universal-Mask-Runtime-Status mit Korrektur vom 22. Oktober und Migration-Parity-Reparaturnachweis; MCP-Schreibstandard und Production-Readiness-Runbook. Der Katalognachweis ist keine Live-Freigabe. Die lokalen Startbefehle wurden aus der bisherigen README übernommen; sie setzen eine konfigurierte Entwicklungsumgebung voraus und wurden bei dieser Dokumentationsänderung nicht ausgeführt.

Annahme: Die genannten Fachbereiche beschreiben den Produktumfang beziehungsweise das Zielbild, nicht gleichmäßige Implementierungstiefe. Details und offene Gates bleiben in den verlinkten Quellen maßgeblich. Keine Datenbank-, Build- oder CI-Läufe für diese reine Textänderung.

Markteinordnung: SAP dokumentiert bereits MCP-gestuetzte, autorisierte Agenten und anpassbare Arbeitsraeume ([Agents](https://help.sap.com/docs/joule-studio/joule-studio/agents?version=CLOUD), [Joule Work](https://architecture.learning.sap.com/docs/ref-arch/bc7811)). Agenten oder adaptive Oberflaechen allein sind deshalb kein belegtes Alleinstellungsmerkmal. Die README beschreibt den angestrebten Mehrwert der agrarspezifischen Kombination und vermeidet unbelegte Marktueberlegenheit, ROI-Zahlen oder Zertifizierungen.
