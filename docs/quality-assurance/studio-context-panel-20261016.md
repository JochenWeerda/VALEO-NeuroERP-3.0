# Studio ohne fremden Arbeitskontext

Die dauerhafte Ernte-Abrechnungszeile im allgemeinen Masken-Studio war irrefuehrend: Sie gehoerte nicht zum jeweils bearbeiteten Entwurf. Der Bereich wird jetzt ausschliesslich beim vorhandenen ausdruecklichen Fachzugang mit harvestControls=1 eingeblendet. Die Registry-Zuordnung agrar/harvest-controls bleibt erhalten; keine Fachaktion, Berechtigung oder Freigabe wird veraendert.

Vier Studio-Bedienvertraege bestanden, einschliesslich fehlender Ernte-Zeile beim normalen Einstieg. Reale lokale Browserpruefung auf /admin/screen-studio: keine entsprechende Zeile; normaler Editor und Maskenuebernahme sichtbar. Sichtnachweis lokal unter artifacts/studio-theme-acceptance/studio-context-clean.jpg. Das ist eine Kontextkorrektur, kein Nachweis der vollstaendigen Belegmigration.
