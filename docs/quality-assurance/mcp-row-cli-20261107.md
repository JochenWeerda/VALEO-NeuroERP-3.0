# CLI Zeilenbefehle — 2026-11-07

Die CLI unterstuetzt die versionierten Zeilenaktionen fuer Onboarding, Qualifikation, Schulungszuordnung und Versandprofil auf denselben POST-Endpunkten wie die Masken. HR verlangt die gelesene Vollzustandsrevision als `--feld expected_revision=...` (64 kleine Hexzeichen); Versand verlangt `--feld expected_active=true` und `--grund`. `--version` ist fuer diese vier Befehle unzulaessig. Trockenlauf, zusaetzliche Eingaben und fehlender Stand werden vor dem Senden abgewiesen. Ein generierter Wiederholungsschluessel wird bei unsicherem Netz-/Serverausgang zum erneuten Aufruf ausgegeben. Token und serverseitige Rollen-/Capability-Pruefungen bleiben massgebend; Agentenaufrufe werden mit dem urspruenglichen Token an den Server weitergegeben; HR-Capabilities sind aktuell deaktiviert und werden serverseitig abgewiesen. Delegierte Identitaeten unterliegen ebenfalls der dortigen Ablehnung. Die CLI erteilt keine Capability-Freigabe.
