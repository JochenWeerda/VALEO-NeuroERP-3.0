# CLI Zeilenbefehle — 2026-11-07

Die CLI unterstuetzt die versionierten Zeilenaktionen fuer Onboarding, Qualifikation, Schulungszuordnung und Versandprofil auf denselben POST-Endpunkten wie die Masken. HR verlangt den unveraenderten ISO-Zeitstempel mit Zeitzone als `--feld expected_updated_at=...`; Versand verlangt `--feld expected_active=true` und `--grund`. `--version` ist fuer diese vier Befehle unzulaessig. Trockenlauf, zusaetzliche Eingaben und fehlender Stand werden vor dem Senden abgewiesen. Ein generierter Wiederholungsschluessel wird bei unsicherem Netz-/Serverausgang zum erneuten Aufruf ausgegeben. Token und serverseitige Rollen-/Capability-Pruefungen bleiben massgebend; als Agent oder delegierte Identitaet wird die deklarierte Menschensperre respektiert. Die CLI erteilt keine Capability-Freigabe.
