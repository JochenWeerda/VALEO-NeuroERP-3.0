# Lokale Laufzeitumstellung

Der Backend- und Migrationsstand stammt exakt aus main 2338578d0. Beide bestehenden
Anwendungscontainer wurden ersetzt; PostgreSQL, Volumes und fremde Datenbanken
blieben erhalten. Das vorhandene local-preview-Profil verwendet einen Backendworker
und den im Image enthaltenen Code statt alter Bindmounts aus dem primaeren Baum.

## Datenbanknachweis

Vor dem Eingriff wurden Vollsicherung und Container-Laufzeitdaten lokal gesichert.
Der vollstaendige Probelauf der 17 ausstehenden Migrationen wurde zurueckgerollt:
Revision, Katalog und Inhaltspruefsummen aller 439 erfassten Tabellen identisch.
Anschliessend lief das kanonische Alembic-Upgrade erfolgreich auf den expliziten
Head wms_pickposition_stand_20261110. 659 Tabellen tragen RLS.
487 Migrationsdateien im Image wurden gegen den freigegebenen Git-Baum geprueft.
Keine Migration aus Claudes ungemergtem BELEG-052-Stapel wurde angewendet oder gestempelt.
Keine Operation auf valeo_claude_test. Backups und Datennachweise bleiben lokal.

## Laufzeitnachweis

Backend /health: HTTP 200. Belegzugriff ohne Anmeldung: HTTP 401.
Frontend auf localhost:3000 und localhost:3001 erreichbar. Ein sauberer Chrome-Kontext
wird von /admin/screen-studio zur nativen Anmeldung umgeleitet; SSO-Schaltflaeche
sichtbar und keine JavaScript-Fehler. Das ist keine angemeldete Fachkettenabnahme.

Der Backendworker benoetigt nach dem Start rund 1,08 GiB statt vier paralleler
Registry-Importe. Requests laufen als valeo_app; der bestehende Systemzugang ist
nur fuer ausdrueckliche mandantenuebergreifende Systemkontexte eingebunden.
Das Profil fuehrt keine automatischen Migrationen beim Start aus.

Beim Browsernachweis wurde eine ignorierte Dunkelwahl auf der Anmeldung entdeckt.
Die separate Korrektur und ihr Auslieferungsnachweis stehen in
[Theme-QA](theme-bootstrap-20261115.md). Schwere Builds und fremde Tests bleiben seriell.

## Wiederaufnahme

Dieses Migrationsfenster ist abgeschlossen. Die 17 Migrationen nicht erneut
manuell ausfuehren oder stempeln. Neue Migrationen erst aus einem neu freigegebenen
Integrationsstand uebernehmen. Claude ist fuer eigene Branches und seine bestehende
Testdatenbank freigegeben; schwere Ressourcennutzung vorher koordinieren.
