# Glossar – Landhandel & Agrar

Zentrale Fachbegriffe. Verlinken Sie aus Anleitungen hierher, statt Begriffe
mehrfach zu erklären.

| Begriff | Bedeutung |
|---|---|
| **Annahme** | Erfassung einer Anlieferung inkl. Wiegung und Qualität. |
| **Erstwiegung / Zweitwiegung** | Brutto- bzw. Taragewicht; Differenz = Nettomenge. |
| **Besatz** | Anteil unerwünschter Bestandteile in einer Probe. |
| **Feuchte** | Wassergehalt; über Grenzwert → Trocknungsabzug. |
| **Trocknungsregel** | Regel für Mengen-/Wertabzug bei zu hoher Feuchte. |
| **Lot / Charge** | Rückverfolgbare Mengeneinheit mit Herkunft und QS-Status. |
| **Silozelle** | Lagereinheit für Schüttgut; trägt Füllstand und QS-Status. |
| **Spülcharge** | Reinigungsmenge bei Materialwechsel zur Vermeidung von Verschleppung. |
| **QS-Status** | Qualitätssicherungs-Status (z. B. freigegeben, gesperrt). |
| **Kontrakt** | Liefervertrag, der über mehrere Anlieferungen erfüllt wird. |
| **Selbstabrechnung (Self-Billing)** | Gutschriftsverfahren: Käufer rechnet für den Lieferanten ab. |
| **Lieferschein** | Beleg über die tatsächliche Lieferung; Bindeglied Auftrag → Rechnung. |
| **Offener Posten (OP)** | Unbezahlte Forderung oder Verbindlichkeit. |
| **Mahnstufe** | Eskalationsstufe im Mahnwesen. |
| **Mandant (Tenant)** | Rechtlich/organisatorisch getrennter Datenraum. |
| **GoBD** | Grundsätze ordnungsmäßiger Buchführung in elektronischer Form. |
| **Nachweisraum (DMS)** | Revisionssichere Dokumentenablage. |
