# Compliance

Nachweis- und auditrelevante Dokumentation. Doku ist hier Teil des
Compliance-Nachweises — revisionssicher, versioniert, datierbar.

## Themen

- **GoBD** — Unveränderbarkeit, Nachvollziehbarkeit, Aufbewahrung.
- **DSGVO** — Verarbeitungsverzeichnis (ROPA), Betroffenenrechte, Löschkonzept.
- **Audit-Trail** — Audit-Logging mutierender API-Aufrufe, Evidence.
- **Mandantentrennung** — Tenant-Isolation als Datenschutz-Maßnahme.

## Versionierung

Je Release wird ein unveränderlicher Doku-Snapshot erzeugt (`mike` + Git-Tag),
der als Compliance-Beleg dient.

> Inhalte folgen in `DOC-GOVERNANCE-001`.
