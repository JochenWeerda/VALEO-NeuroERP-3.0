# Workflow Documentation

## Zweck

Dieser Bereich beschreibt, wie End-to-End-Workflows analysiert, in Cards zerlegt, fachlich gegen die Praxis geprueft und UI-/CRUD-seitig validiert werden.

## Reihenfolge

1. relevante Doku unter `docs/project-context/` lesen
2. passenden Workflow festlegen
3. Workflow in Cards zerlegen
4. Mermaid-Diagramm erzeugen
5. Soll-Ist-Abweichungen dokumentieren
6. UI-/CRUD- und Browser-Use-Pruefung durchfuehren
7. Fehler beheben
8. Doku aktualisieren
