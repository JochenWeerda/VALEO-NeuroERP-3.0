    Right-to-Delete¶

    • [ ] API-Endpoint: /api/v1/gdpr/delete-user/{user_id}
    • Löscht alle persönlichen Daten

    • Cascade-Logic für abhängige Datensätze

    • [ ] Anonymisierung statt Löschung
